# Dashboard Layout Rules v1.0

## 전체 레이아웃 원칙
1. F-Pattern: 최상단 KPI 요약 → 주요 차트 → 보조 분석 → 상세 테이블
2. 다크 테마 전용 (금융 대시보드 표준)
3. 모바일 우선 반응형 (Mobile-First Responsive)
4. 컴포넌트 최소 단위: 카드 (bg-[#1a1d27], border border-[#2d3142], rounded-xl)

## 컴포넌트별 스펙

### KPI Bar (최상단 고정)
위치: 헤더 바로 아래, 전체 너비
높이: 80px (모바일: 60px, 스크롤 가능)
카드 최소 너비: 140px (모바일: 120px)
내부 구성:
  - 레이블: text-xs text-gray-400 mb-1
  - 수치: text-2xl font-bold text-white
  - 변화율: text-sm (양수=#26a69a, 음수=#ef5350)
  - 단위: text-sm text-gray-400 ml-1

### 메인 차트 패널
레이아웃: lg:grid-cols-5
  - 주요 차트: lg:col-span-3 (60%)
  - 사이드 패널: lg:col-span-2 (40%)
차트 높이:
  - 데스크탑: 380px
  - 태블릿: 300px
  - 모바일: 250px

### 인사이트 패널
배경: bg-[#1a1d27] border border-[#2d3142]
각 인사이트 아이템: bg-[#0f1117] rounded-lg p-3
텍스트: text-sm text-gray-200 leading-relaxed
로딩 상태: 스켈레톤 애니메이션 (pulse 효과)

### 데이터 테이블
배경: bg-[#1a1d27]
헤더: bg-[#12151f] text-xs text-gray-400 uppercase
행 호버: hover:bg-[#2d3142]
최대 표시: 100행 (페이지네이션 또는 접기/펼치기)

## 인터랙션 규칙
- 차트 호버: 툴팁으로 정확한 수치 표시
- 기간 선택기: 1M / 3M / 6M / 1Y / 3Y / ALL
- 차트 확대: 핀치/드래그 줌 지원
- 테이블 정렬: 컬럼 클릭 시 오름/내림차순
- 반응형 전환: CSS Grid 자동 조정 (grid-cols-1 → grid-cols-5)
